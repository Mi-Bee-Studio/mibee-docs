# 远程桌面会话

## 会话内能力

| 能力 | 说明 |
|---|---|
| 视频 + 键鼠 | tile 化多分辨率编码，弱网自动降帧降码率，恢复自动爬坡 |
| 剪贴板 | 文本 / 图片 / 文件双向同步，正常复制粘贴即可 |
| 文件互传 | 拖拽或会话工具栏，接收目录在设置页配置（默认 下载目录/MiBeeReach） |
| 音频 | 被控端声卡回环采集，工具栏开关 |
| 多显示器 | `Ctrl+Alt+N` 循环切换远端显示器 |
| 只读模式 | 配对授权的会话级权限；开启后本端输入被禁用 |
| 录屏输出 | 被控端 `--record` 启动时，主控端可开关远端 RTSP 录制（`Ctrl+Alt+R`） |
| 背景置黑 | `Ctrl+Alt+B`——远端物理显示器熄屏，省带宽也防窥屏 |

## 快捷键速查

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Alt+0` | 画面适应窗口 |
| `Ctrl+Alt+±` | 缩放 ±25% |
| `Ctrl+Alt+N` | 切换显示器 |
| `Ctrl+Alt+Q` | 画质档位循环 |
| `Ctrl+Alt+M` | 音频开关 |
| `Ctrl+Alt+B` | 背景置黑开关 |
| `Ctrl+Alt+R` | 录屏输出开关 |
| `Ctrl+Alt+I` | 远程状态浮窗（帧率 / 延迟 / 码率） |
| `Ctrl+Alt+F` / `F11` | 全屏（`Esc` 退出） |
| `Esc` | 退出全屏 / 释放指针锁 |

## 状态浮窗

`Ctrl+Alt+I` 打开独立浮窗，实时显示：**Path**（直连/中继）、**Peer**（对端地址）、
**Rate**（上下行速率）、**Qual**（链路质量分档与 RTT）、**Frame**（帧率与编码耗时）、
FPS / 码率。静态桌面无帧时，RTT 仍由 ICE 层 1Hz 刷新（不依赖视频帧）。

## 自动重连

会话中断后控制台按指数退避自动重连（页签徽章显示「重连中」）；被控端不可达时
viewer 先报真实错误原因，不傻等。被控端 host 进程死亡后需重新拉起（Windows 安装
包的可选开机自启会负责这一步）。

## 性能特性

- **无人观看几乎零 CPU**：画面无变化时捕获自动「停车」，编码器释放；
- **可选硬件编码**：设置页「编码后端」切自动/强制（Windows 支持 AMD AMF 硬编，
  需被控端带 AMF 运行时）；
- **弱网自适应**：码率死区 + 定时上调策略，坏链路画质平滑降档、恢复后快速爬回。
