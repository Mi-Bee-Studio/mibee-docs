# 常见问题与故障排除

## 发现与连接

**Q：主控端的设备列表里看不到被控端？**
按顺序检查：① 两端是否同一网段（跨 VLAN 不通）；② 被控端 host 是否在跑
（Windows 看托盘 / Linux `ss -lunp | grep 7777`）；③ 路由器是否开启
AP 隔离 / 客户端隔离（会拦广播发现）。都不行就用快速连接手输 `ip:port`。

**Q：连接超时？**
被控端防火墙放行对应 **UDP** 端口（桌面 7777 / 终端 7778 / 隧道 7779）。
注意是 UDP 不是 TCP——拿 TCP 探测工具测 7777 必然显示不通，这是误判。

**Q：提示认证失败 / auth rejected？**
两端 LAN 访问码不一致。被控端 `reach desktop lan-key` 查看，主控端控制台
输入位或 `--lan-key` 对齐。

**Q：换了网络后被控端「消失」了？**
信标发现只覆盖同网段。新网段里用 `ip:port` 直连；被控端的信标每 3 秒广播，
主控端离开再回到该网段会重新发现。

## 会话

**Q：画面卡顿 / 帧率低？**
画质档位切「省流」（`Ctrl+Alt+Q`）；无线链路优先 5GHz；检查被控端是否
在跑重负载。弱网下码率自适应会自动平滑降档，恢复后快速爬回。

**Q：静态画面时状态浮窗 FPS 显示 0？**
这是真实值——画面无变化时不产生编码帧，捕获自动「停车」省 CPU；此时
RTT/速率仍由 ICE/控制流持续刷新。

**Q：远程桌面打开后远端屏幕看不出来在动？**
检查是否开启了「背景置黑」（`Ctrl+Alt+B`）或被控端 `--record` 录制策略
对物理输出熄屏——这些是为防窥屏/省带宽设计的，属正常行为。

**Q：剪贴板/文件互传不工作？**
配对授权面包含剪贴板与文件才可用；被控端托盘退出重启后重新连接一次。
Linux 被控端需桌面会话在跑（Wayland/X11）。

**Q：macOS 控制台打不开？**
右键 → **打开** 放行 Gatekeeper（ad-hoc 签名包首次启动的常规提示）。

## 其它

**Q：如何在 Linux 上开机自启？**
把 host 命令写成 systemd user unit 或系统 unit，`Restart=always`；
参考：

```ini
[Service]
ExecStart=/opt/reach/reach desktop host --bind 0.0.0.0:7777 --fps 20
Restart=always
```

**Q：想要跨网（离开局域网）连接？**
v0.1.0 公开发布为局域网直连版；跨网能力属后续版本规划。
