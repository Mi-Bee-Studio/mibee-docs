# 产品介绍

**MiBeeReach** 是 MiBee 生态的远程接入产品：**远程桌面、远程终端、SSH、端口转发**共享同一连接层与同一设备身份，全程走你自己的局域网——**无账号、无云、不经第三方**。

一句话：在需要被连接的机器上装一个 **Host**（被控端），在你手头的机器上开一个**控制台**（主控端），同网段自动发现、点一下就连——桌面、终端、文件、剪贴板、音频，全都到得了。

## 它解决什么

| 商用远程桌面服务的痛点 | MiBeeReach 的回答 |
|---|---|
| 限速 / 限额 | 自有基础设施——不限速、不限额 |
| 广告打扰 | 纯工具，无广告 |
| 隐私黑盒（流量过厂商服务器） | 全程局域网加密传输，流量不出你的网络 |
| 画质 / 延迟不可控 | 全链路自研，弱网自适应画质、无人观看几乎零 CPU |

## 能力版图

| 能力 | 说明 |
|---|---|
| 远程桌面 | 视频、键鼠、剪贴板（文本 / 图片 / 文件）、音频、文件互传、多显示器、只读模式、录屏输出 |
| 远程终端 | 远程 shell，与桌面同一传输层 |
| 远程 SSH | 内置 SSH server，任意标准 `ssh` 客户端可直连 |
| 端口转发 | 把内网 TCP 服务安全地暴露给主控端本地端口 |
| 管理控制台 | 桌面应用：快速连接、局域网设备发现、工作区页签、内嵌终端、SSH 会话、会话监控 |

## 平台

| 角色 | 平台 |
|---|---|
| 被控端（Host） | Windows x64 · Linux x86_64 · Linux arm64 |
| 主控端（控制台） | Windows x64 · macOS arm64（Apple Silicon） |

## 设计原则

1. **隐私优先**：连接一律加密，流量不出局域网，路径上没有第三方。
2. **必须配对**：无凭据的连接直接拒绝；已配对设备免确认连接。
3. **弱网可用**：画质自适应、无人观看时几乎零 CPU、可选硬件视频编码。
4. **会话级权限**：控制、剪贴板、文件分别授权，另有只读模式。
