# 控制台巡礼

控制台（`reach-config.exe` / `MiBeeReach.app`）分三个页面：**连接 / 工作区 / 设置**，左侧导航切换。工作区不占顶部导航高度，远程画面竖向空间最大化；全屏时整条侧栏隐藏。

## 连接页（默认）

- **快速连接**：单框智能路由——填 `ip:port` 走局域网直连；旁边可选填 **LAN 访问码**（配对门禁，见[配对](pairing.md)）。
- **设备区**：同网段被控端自动发现（信标每 3 秒广播、15 秒新鲜窗），免登录零配置；每张卡显示在线状态与地址，点「连接」即开桌面。
- **SSH 会话**（折叠卡）：保存「设备 + 用户名」预设，一键以内嵌终端页签打开。
- **会话监控**（折叠卡）：所有活跃会话的实时速率 / RTT / FPS / 码率表，3 秒刷新。

## 工作区页

所有进行中的会话以页签呈现（远程桌面 / 内嵌终端 / SSH）。顶部一条 36px 工具栏只在**活跃桌面页签**时出现：

| 工具 | 作用 |
|---|---|
| 缩放组 | 适应 / 拉伸铺满 / 100% / ±25% / 全屏 / 拉出独立窗口 |
| 显示器 | 切换远端显示器（`Ctrl+Alt+N`） |
| 画质 | 档位循环：原画 → 省流 → 均衡（`Ctrl+Alt+Q`） |
| 音频 | 传输开关（`Ctrl+Alt+M`；关 = 0 音频带宽） |
| 录制 | 录屏输出开关（`Ctrl+Alt+R`；被控端需 `--record` 启动） |
| 状态 | 远程状态浮窗：帧率 / 延迟 / 码率（独立窗口中 `Ctrl+Alt+I`） |

全屏（`Ctrl+Alt+F` 或工具栏）时整条侧栏与工具栏收纳，`Esc` 退出。

## 设置页

- **桌面默认**（被控端启动参数）：默认 FPS、捕获超时、tile 行列、捕获比例、显示比例、文件接收目录、编码后端（自动 / 强制软编 / 强制硬编）。
- **被控端默认监听地址**：桌面 7777 / 终端 7778 / SSH 2222 / 隧道 7779。
- **隧道与 Shell**：默认转发目标与本地端口、默认 shell。
- **界面偏好**：连接成功自动全屏（默认关）、内嵌终端字号。仅存本机，不进远端配置。
