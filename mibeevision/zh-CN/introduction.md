# 产品介绍

**MiBeeVision** 是 MiBee 生态的视频流 AI 后期处理引擎，也是 **MiBeeNvr** 的「AI 大脑」：对 NVR 录下的视频做**目标检测、多目标跟踪与区域规则判定**，输出结构化事件与带框快照，并直接回写 NVR。

一句话：NVR 负责「录得下」，MiBeeVision 负责「看得懂」——录像生成后自动逐段分析，录像列表上每一段都被打上 AI 标记，人/车出现、区域入侵、越界、徘徊都变成可回查的事件。

## 它和 NVR 内置的浏览器端 AI 有什么不同

MiBeeNvr 自带浏览器端 AI 检测（推理跑在浏览器的 Web Worker 里），两者**互补而非替代**：

| | 浏览器端 AI 检测（NVR 内置） | MiBeeVision（服务端） |
|---|---|---|
| 运行位置 | 浏览器内 Web Worker | 独立进程（可与 NVR 同机或分机部署） |
| 分析时机 | 打开页面时的实时画面 | 录像生成后逐段自动分析，7×24 不依赖页面开着 |
| 事件留存 | 以实时画框为主 | 结构化事件落库 + 带框快照，可回查可追溯 |
| 规则 | ROI 多边形（只圈区域内目标） | 区域入侵 / 越界 / 徘徊等事件规则 |
| 结果去向 | 实时画面 | 回写 NVR：录像列表 AI 标记 + AI 事件 |

## Lite / Pro 两种形态

MiBeeVision 使用独立版本线（`mibee-vision-vX.Y.Z`），与 MiBeeNvr 的 `vX.Y.Z` 版本线相互独立。

| | **Lite（已发布 · 免费）** | **Pro（规划中，发布时间待公布）** |
|---|---|---|
| 当前版本 | v0.1.0（2026-10 发布） | — |
| 摄像头 | 单摄像头 | 多摄像头 |
| 推理 | CPU（ONNX Runtime） | GPU 加速（CUDA / TensorRT） |
| 分析方式 | 录像生成后逐段分析 | 另含历史录像批量补分析 |
| 分发 | 随 MiBeeNvr 发布页免费分发 | 待公布 |

当前版本的能力清单见[能力总览](features.md)；安装与快速开始见[部署](deployment.md)。

## 许可

- **软件本体**：闭源专有软件，版权归 MiBee Studio 所有。Lite 版随 MiBeeNvr 免费分发。
- **内置检测模型 YOLOv8n**：采用 Ultralytics **AGPL-3.0** 许可——使用本程序进行检测即视为接受 AGPL-3.0 的相关义务；**商业闭源分发需另行取得授权**（或将模型替换为宽松许可模型）。

## 技术形态

- **Rust 单二进制**：Linux x86_64 / aarch64 双架构，无外部依赖（ONNX Runtime 动态库随包提供）。
- **ONNX Runtime 推理**：CPU 起步，内置 YOLOv8n 检测模型。
- **FFmpeg 解码**：直接消费 NVR 录像段，无需额外转码。
- **ByteTrack 多目标跟踪**：跨帧关联，目标有稳定轨迹。
- **内嵌 Web 配置页**（默认端口 `:9092`）：填 NVR 地址与 API Key、选择摄像头、配置规则区域，保存即生效，无需手工编辑配置文件。

## 生态位置

```
摄像头 → MiBeeNvr（接入/录像/存储中枢）
              │ 录像段（同机共享目录 或 HTTP 下载）
              ▼
        MiBeeVision（检测 → 跟踪 → 规则判定）
              │ 事件 + 快照 + AI 状态回写
              ▼
        MiBeeNvr（录像列表 AI 标记 + AI 事件）
```
