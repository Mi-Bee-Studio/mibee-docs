# 产品介绍

[English](../en-US/introduction.md)

**MiBeeHive（蜂巢）** 是 MiBee 生态的自托管运维补给站：把**装机、补料、共享、巡检**四件日常运维事收进一个 Web 界面。部署在你的 ARM64 NAS 或任意小主机上，内网的机器从此有了一个统一的"补给与运维"入口——数据、脚本、镜像全部落在你自己的设备上。

一句话：外部发行源（GitHub Releases、Go 模块、NPM、PyPI 等）经蜂巢"采蜜"落到本地；裸机经 PXE"哺育"自动装机；文件经 WebDAV"分享"给内网；设备与任务由运维中心"巡检"看护。

![MiBeeHive 生态位置：外部发行源经蜂巢补给内网设备](images/supply.svg)

## 它解决什么

| 家庭/小团队实验室的日常痛点 | MiBeeHive 的回答 |
|---|---|
| 内网带宽慢，每个设备都去公网拉同一个发行版 | 采蜜一次、全内网复用——发行版统一落地本地 |
| 装一台新机器要找镜像、写应答文件、插显示器键盘 | 系统部署：PXE 网络启动 + 无人值守应答模板，网线插上即装机 |
| 团队文件散落在各处，权限混乱 | WebDAV 分享：统一入口、可配只读/读写 |
| 脚本、密钥、备份散落在各台机器上 | 运维中心：计划任务、密钥管理、备份恢复集中一处 |
| 设备状态没人看，磁盘满了才知道 | 系统状态仪表盘 + 磁盘阈值告警 + Prometheus 指标 |

## 能力版图

| 模块 | 说明 |
|---|---|
| 文件中心（采蜜） | 从 GitHub / Go / NPM / PyPI / HashiCorp / Grafana 等公共源抓取发行版到本地：项目管理、下载队列、API 令牌、全文搜索 |
| 系统部署（哺育） | 无人值守 OS 安装：PXE 网络启动端点、preseed/kickstart/autoinstall 应答模板、ISO 目录与下载管理 |
| 分享 | WebDAV 文件服务：匿名只读 + 管理员读写可选，支持 HTTPS（含自签证书） |
| 运维中心 | 容器管理（启停/日志/统计/镜像/应用模板）、计划任务（定时脚本+日志）、密钥管理、备份与恢复、系统状态 |

## 设计原则

1. **单二进制，零依赖**：一个可执行文件内嵌完整 Web 界面，SQLite 存储，无外部数据库、无消息队列——NAS 上扔进去就能跑。
2. **为低配设备设计**：ARM64 NAS（1GB 内存级别）即可流畅运行；资源占用以"树莓派能跑"为验收线。
3. **数据全部本地**：采蜜的发行版、装机的镜像、共享的文件、备份的档案都在你自己的磁盘上，不经任何第三方。
4. **面向内网**：定位是内网补给站，不暴露公网；需要远程运维能力时配合内网穿透/VPN 自行组网。
